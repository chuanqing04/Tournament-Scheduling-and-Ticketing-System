# Tournament Scheduling and Ticketing System

This project is a tournament scheduling and ticketing system developed as part of a programming assignment. It focuses on managing tournament schedules and ticketing-related activities through a software application.

## Features

The system is designed around the following functions:

- **Tournament Scheduling** – Organizing tournament events and schedules.
- **Tournament Information** – Managing information related to tournaments.
- **Ticketing** – Handling ticket-related activities for tournament events.
- **Record Management** – Organizing tournament and ticketing information.

## Technologies Used

- Visual Studio
- .NET project environment

## How to Run the Project

1. Install Microsoft Visual Studio with the required .NET development tools.
2. Download or clone this repository.
3. Open the `Assignment #2.sln` file in Visual Studio.
4. Restore any required project dependencies.
5. Build the solution.
6. Run the project through Visual Studio.

## Project Information

This project was developed as part of a university programming assignment to apply programming concepts in creating a tournament scheduling and ticketing system.
